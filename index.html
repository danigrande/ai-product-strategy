The Bet

What we're building, for whom, and why now

Three-Axis Vulnerability Diagnostic

M1 · diagnostic.md
Product: Worldcup Pool (Agente Mundial)
Role: Product Manager
Contextual Moat
2 / 5
Mid-tournament lock-in is near-absolute — stateful leaderboard, social graph, and personalized AI banter mean users can't migrate mid-World Cup. However, pre-tournament switching cost is near-zero. Before the first match, users easily move to a competitor.

Attacker: Fantasy league equivalents, online spreadsheets.
Data Advantage
5 / 5
Niche RLHF on social sports banter. Every 👍/👎 on AI messages captures prompt, RAG context, and user stats — a dataset no foundation model has. Compounds toward a DPO-fine-tuned open-source model that outperforms frontier models on this specific roast-your-friends task at a fraction of the cost.

Risk: Relies on third-party APIs for live results.
Platform Exposure
5 / 5
Low encroachment risk: Apple/Google/OpenAI build horizontal platforms, not hyper-niche, culturally specific gamified social apps. The real threat is platform AI making it trivially easy for users to hack together a "good enough" solution inside WhatsApp/Telegram. Defense relies on dedicated UI, zero-friction tap-to-predict, and deterministic (non-hallucinating) game logic.

Top Vulnerabilities

1. Post-Event Churn: The World Cup lasts one month. DAU drops ~100% the day after the final. Mitigation: treat the World Cup as top-of-funnel acquisition; roll groups into La Liga / Premier League / Champions League pools post-tournament.

2. LLM Unit Economics: Noisy group chats can explode token usage. If 10 friends send 500 messages during a match and the bot analyzes each one, costs scale linearly with success. Mitigation: rate limiting, model routing (cheap Groq for banter, frontier for summaries), and the Admin-Sponsored Group Pass ($4.99).

Revenue strategy still undecided — Freemium with paid capabilities vs. free with ads + data exploitation.

Weakest Loop: Network Loop — users in siloed groups don't improve the AI for other groups

Correction Loop — 3/5

Users can 👍/👎 AI messages with an optional reason, securely logged to MongoDB (ChatbotFeedback). However, there is no automated retraining pipeline — signal is captured for manual review but not dynamically reused. To reach 4/5: implement dynamic few-shot prompting by injecting past upvoted interactions into the prompt.

What you capture: Thumbs up/down on Agent messages + reason selection.

Preference Loop — 4/5

Static personalization via User.js (likes, dislikes, humor_style) plus short-term RAG memory of recent chat context. Repetition avoidance via recentBotOutputs. Next step: automated fact extraction — a cron job that analyzes daily chat logs and permanently updates user profiles with new preferences.

What you capture: Last 100 messages per user via RAG + user-selected tone & personality preferences.

Domain Context Loop — 3/5

Data flows unidirectionally: News (RSS) and Game state (leaderboard) feed into Chat, but chat output doesn't improve News or Game domains. Next step: tie the RSS feed engine to prediction data — if 80% of users bet on an underdog, auto-add that team to RSS keywords.

Network Loop — 2/5

Strong intra-group local effects (inviting friends makes a single group better) but zero inter-group global effects. A group in Argentina doesn't improve the experience for a group in Spain. Quick fix: add a "Wisdom of the Crowds" feature showing aggregate prediction data across all groups.

Encroachment Threat Assessment

M2 · data-flywheel.md

1. Platform Encroachment

Attacker: Meta (WhatsApp) / Apple Intelligence
Vector: Native AI agents in default group chats.
Time-to-threat: 1–2 years
Value at risk: 30–40% — dedicated UI/UX is the defense.

2. Vertical Competitor

Attacker: Sleeper / ESPN / Yahoo Fantasy
Vector: Incumbent social fantasy sports adding AI commish.
Time-to-threat: 6–12 months
Value at risk: 90–100% — existential if target users are already on Sleeper.

3. Adjacent Expansion

Attacker: Telegram Mini-Apps / Bot developers
Vector: Frictionless distribution inside existing chat apps.
Time-to-threat: 3–6 months
Value at risk: 70–80% — attacks the GTM friction of getting 10 friends to download a new app.

90-Day Encroachment Plan: Meta (WhatsApp)

M2 · data-flywheel.md
  • Attack vector: Your weakest loop is GTM friction — Meta attacks by launching the feature exactly where friend groups already live.
  • Weeks 1–4: Meta rolls out "WhatsApp Sports Bots" powered by Llama 3. Any user types @MetaAI start a World Cup pool and a native leaderboard pins to the chat.
  • Weeks 5–8: One week before the World Cup, the "Alpha" friend tries to get the group on Agente Mundial, but 3 friends complain. They give up and use WhatsApp instead.
  • Weeks 9–12: Tournament is mid-knockout stage. Users are permanently locked into WhatsApp for the event — stateful points and banter history can't migrate mid-tournament.
  • Your defense: Hyper-vertical brand safety moat (Meta AI is too polite to be genuinely funny), dedicated UX (chat is a terrible interface for complex stats), and "Sanctuary" positioning (groups want a dedicated app to separate game noise from daily life).

Cascading Strategy

Triage model: Llama 3.1 8B (via Groq) — for real-time chat banter. Speed matters: 500+ tokens/sec.
Frontier model: GPT-4o-mini or Claude 3.5 Haiku — for daily summaries and data extraction (accuracy-critical, async, latency-tolerant).
Routing rule: Synchronous chat → triage. Asynchronous cron jobs (daily summaries) → frontier.
Expected ratio: 95% triage / 5% frontier — blended COGS stays near open-source pricing.

Pricing Model: Admin-Sponsored Group Pass

Free Tier: Create groups, invite friends, enter predictions, view leaderboard — zero friction.
Group Pass ($4.99 one-time per tournament): The Group Admin pays once. Unlocks AI personalities, daily summaries, and breaking news RSS for the entire group for 30 days.
Margins: AI COGS ~$0.35 per group per month → 93% gross margin at $4.99.

Board One-Pager — The AI Margin Expansion

A static digital spreadsheet. Users check a math-based leaderboard. Churn when losing. No monetization path.

A dynamic game commentated by AI personas. Automated engagement (daily summaries, roasts, news). Users in last place stay for the humor. $4.99 Group Pass unlocks AI features.

Net margin shift: Free un-monetizable utility → premium entertainment at >90% gross margins. CAC decreases via shareable AI-generated content.

Golden Dataset & Reliability Contract

M4 · golden-dataset.md

Reliability Contract

MetricTargetMeasurementAlert Threshold
Accuracy 92% Weekly · 300 golden rows · LLM-as-Judge (GPT-4o, accuracy rubric) <88% → page on-call
Hallucination rate <1% Same weekly run · safety rubric flags fabricated policies/numbers >2% → auto-rollback to last good model
Latency (p95) <800ms Continuous prod monitoring (Datadog) · p95 by endpoint >1,200ms for 5min → page on-call
Drift velocity <0.5%/wk 4-week rolling accuracy trend vs. golden dataset >1% decay/wk → trigger gold-set audit

HITL Architecture

Trigger: Confidence <60% OR safety rubric flag fires on a customer-facing output.
Reviewer: Rotating PM on-call (weekday 9–5 ET) · senior CSM after hours.
Feedback loop: Reviewer corrections feed into weekly gold-set audit. 5+ corrections in a week triggers a model retrain candidate.
